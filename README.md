# 地球 Online 玩家测试

一个轻量的网页人格/门派测试小游戏。玩家回答随机抽取的问题后，会得到自己在「地球 Online」服务器中的门派归属、核心属性、天赋短板、生存攻略和玩家信号。

这个项目是一次 vibe coding 小实验：把一个有点中二、有点浪漫的想法，借助 AI 快速变成可以被打开、体验和分享的网页作品。

## 在线体验

[https://brunsonliu.github.io/earth-online-test/](https://brunsonliu.github.io/earth-online-test/)

## 功能特色

- 纯前端静态页面，无需后端服务
- 随机抽取 12 道题进行测试，第 12 题为固定压轴题
- 根据回答统计门派倾向并生成结果页，平票时随机裁决
- 包含门派属性条、分布占比、角色独白等展示
- 每个门派带稀有度设定（传说/史诗/精锐/人气），结果页与分享图均展示
- 八门派契合度体系（同频共振/天生互补/相互点亮/需要翻译/平行线），结果页可查看任意两门派关系解读
- 分享链接与二维码携带门派参数，好友通过邀请链接测完可直接看到双方契合度
- 一键保存 1080×1440 结果分享图，图内含稀有度徽章、最佳搭档与入局二维码，支持一键复制文字版玩家档案
- 适配移动端和桌面端浏览器

## 创作想法

我喜欢探索，也对 AI 辅助创作保持热情。这个小项目不追求复杂技术栈，而是尝试用很轻的方式完成一个完整体验：

- 从一个概念出发，设计世界观和门派气质
- 用题库和计分逻辑把体验串起来
- 用动效、字体和结果文案营造氛围
- 部署到 GitHub Pages，让想法真正变成一个可以访问的作品

## 项目结构

```text
.
├── index.html          # 页面结构
├── style.css           # 页面样式和动画
├── data.js             # 门派、题库和属性数据
├── app.js              # 测试流程、结果渲染与分享图生成
├── qrcode.js           # 二维码生成库（MIT，分享图内绘制入局码）
├── og.png              # 社交分享卡片缩略图（1200×630）
├── .github/workflows/  # GitHub Pages 自动部署配置
└── README.md
```

## 本地运行

这个项目是纯静态页面，直接用浏览器打开 `index.html` 即可。

也可以在项目目录启动一个本地静态服务：

```bash
python -m http.server 8000
```

然后访问：

```text
http://localhost:8000
```
